# دکوتک — سایت معرفی و شوروم سه‌بعدی

رابط فارسی و RTL، الهام‌گرفته از تصویر مرجع: صفحه معرفی تیره/طلایی، تصویر آشپزخانه،
نوار دسته‌ها، خدمات و مجموعه‌ها. تصویر معرفی یک تصویر تولیدشده و الهام‌بخش است؛
شوروم تعاملی از مدل‌ها و هندسه واقعی Three.js استفاده می‌کند، نه تصویر یا پانورامای ثابت.

## مسیر مشتری

- کلیک «ورود به آشپزخانه» برای ورود به فضای آماده و ثابت.
- مشتری **ابعاد وارد نمی‌کند**. ابزار افزودن/حذف/جابه‌جایی یونیت، پلان، برآورد و اندازه‌ها در این مسیر نمایش داده نمی‌شوند.
- آشپزخانه شامل ردیف اصلی، کابینت جانبی، جزیره، صندلی و چراغ آویز است.
- دید انسانی با ارتفاع ثابت؛ `W A S D` یا کلیدهای جهت برای حرکت، کشیدن تصویر برای نگاه کردن.
- کنترل‌های لمسی جهت‌دار برای موبایل؛ خروج از پنجره/لغو لمس، حرکت را متوقف می‌کند.
- برخورد دوبعدی با محدوده اتاق، کابینت‌ها، جزیره و صندلی‌ها؛ محدوده بازشوها محافظه‌کارانه است.
- کلیک کوتاه روی هر درب یا کشو، همان بازشو را مستقل باز/بسته می‌کند. کشیدن تصویر بازشو را تغییر نمی‌دهد.
- کشو شامل نمای جلو، کف، دیواره و پشت است و با انیمیشن جلو می‌آید.
- متریال MDF، هایگلاس، نئوکلاسیک، شیکر، ممبران و شیشه‌ای؛ رنگ درب، صفحه، دستگیره، رنگ لوازم و LED قابل تغییر هستند.
- تغییر حالت بین قدم زدن و نمای چرخشی ۳۶۰ درجه؛ ورود به نمونه کمد دیواری با درب‌های ریلی قابل بازشدن.
- عکس PNG از صحنه و ذخیره/کپی خلاصه انتخاب‌ها.

**مشاوره:** اطلاعات تماس واقعی و ارسال سفارش به سرور هنوز تنظیم نشده‌اند. دکمه مشاوره فقط
خلاصه انتخاب‌ها را نمایش می‌دهد و امکان ذخیره/کپی دارد؛ ادعای ارسال سفارش نمی‌کند.
نام برند قابل تغییر است.

## اجرا

در پوشه `cabinet-studio`:

```bash
npm install
npm run dev
```

سپس `http://localhost:5173` را باز کنید. برای توقف سرور `Ctrl+C`.

```bash
npm run build
npm test
```

فونت محلی و تصویر معرفی بسته‌بندی می‌شوند. مدل‌های شوروم بافت‌های procedural دارند و
HDRI یا مدل سه‌بعدی خارجی دانلود نمی‌کنند. کد Three.js فقط هنگام ورود به شوروم بارگیری می‌شود.
HMR از میزبان و پورت صفحه استفاده می‌کند و روی Windows localhost نیز کار می‌کند.

## ساختار مهم

- `src/CustomerApp.jsx`: مسیر اصلی مشتری، صفحه معرفی، انتخاب ظاهر و کنترل‌های حرکت.
- `src/styles/customer.css`: ظاهر واکنش‌گرا مطابق جهت بصری مرجع.
- `src/ui/SceneView.jsx`: بوم سه‌بعدی، عکس و نمایش خطای WebGL.
- `src/three/WalkControls.jsx`: حرکت دید انسانی، نگاه با موس/لمس و مدیریت کلیدها.
- `src/lib/navigation.js`: ابعاد داخلی ثابت شوروم، محدوده مبلمان و منطق برخورد قابل تست.
- `src/three/Drawer.jsx`: کشوی کامل و انیمیشن بازشو.
- `src/three/ShowroomFurniture.jsx`: جزیره، کابینت جانبی، صندلی و چراغ.
- `src/three/kitchen.jsx`: درب‌ها و کشوهای مستقل ردیف اصلی و یونیت‌های دیواری.
- `src/store/useStudio.js`: تنظیمات متریال و وضعیت مستقل بازشوها؛ persist نسخه ۴.

`App.jsx` و پنل‌های ویرایشگر قبلی برای حفظ کد و تست‌های پیشین باقی مانده‌اند، اما
`main.jsx` فقط `CustomerApp` را اجرا می‌کند. مشتری به ویرایشگر فنی دسترسی ندارد.

## تست‌ها

| دستور | پوشش |
| --- | --- |
| `test:logic` | ۱۱ تست چیدمان، برش، هندسه و برآورد |
| `test:ui` | ۲۸ تست رابط و منطق ویرایشگر قبلی |
| `test:scene` | ۴۱ تست هندسه، انواع یونیت، سبک‌ها، صفحات و کمد |
| `test:customer` | ۱۸ تست صفحه مشتری، نبود ابزار ابعاد، حرکت و برخورد، کلیک واقعی بازشو، استقلال درب/کشو، انیمیشن و هندسه جزیره |

تست‌های صحنه از `ReactThreeTestRenderer` استفاده می‌کنند. صفحه معرفی در Chromium هدلس مشاهده شده است. **گرفتن تصویر نهایی شوروم WebGL با رندر نرم‌افزاری این محیط به timeout رسید و بررسی بصری کامل نور/سایه انجام نشد**؛ تست هدلس جای مشاهده در مرورگر را نمی‌گیرد.
بازسازی سه‌بعدی هندسی عین‌به‌عینِ آشپزخانه عکس مرجع نیازمند مدل/نقشه و بافت‌های اختصاصی است؛
این نسخه چیدمان آماده و هم‌جهت با مرجع است.
