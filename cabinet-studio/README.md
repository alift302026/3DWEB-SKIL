# کابینه استودیو — کانفیگurator سه‌بعدی کابینت و کمد دیواری

یک وب‌اپ سه‌بعدی زنده (RTL، فارسی) که مشتری می‌تواند آشپزخانه یا کمد دیواری خودش را
بسازد، متریال و رنگ و یراق را عوض کند، لوازم بگذارد، نورپردازی کند و برآورد قیمت بگیرد.

![three.js](https://img.shields.io/badge/three.js-0.169-black) ![react](https://img.shields.io/badge/react-18-blue)

## اجرا

```bash
cd cabinet-studio
npm install
npm run dev        # http://localhost:5173
npm run build      # خروجی پروداکشن در dist/
npm test           # هر سه مجموعه تست (منطق، رابط، صحنه سه‌بعدی)
```

## قابلیت‌ها

**طراحی کابینت**
- چیدمان پارامتریک یونیت‌ها: درب‌دار، کشو، درب+کشو، سینک، گاز رومیزی، قفسه باز،
  کمد ایستاده، فر توکار، ظرفشویی و یخچال
- جابه‌جایی باکس‌ها با درگ در پلان دوبعدی، با کلیدهای جهت‌دار، یا با دکمه‌های پنل
- تغییر عرض هر یونیت (با محدودسازی به بازه مجاز هر نوع)، تغییر نوع، تکثیر و حذف
- باز و بسته شدن درب‌ها و کشوها با انیمیشن (دابل‌کلیک روی یونیت یا کلید `O`)

**متریال و زیبایی**
- ۶ سبک درب: MDF مات، هایگلاس، نئوکلاسیک (قاب ابزارخورده)، شیکر، ممبران، شیشه‌ای
- ۱۶ رنگ درب، ۵ رنگ بدنه، ۸ صفحه کابینت (کوارتز/گرانیت/چوب/بتن/ترازو) با ضخامت متغیر
- ۶ مدل دستگیره (میله‌ای، بلند، دکمه‌ای، لبه‌ای J-pull، چرمی، مگنتی) × ۶ رنگ یراق
- ۶ نمای آماده یک‌کلیکی + پیشنهاد تصادفی
- همه بافت‌ها (چوب، سنگ، سرامیک، پارچه، استیل خش‌دار) به‌صورت **procedural** در مرورگر
  ساخته می‌شوند — هیچ فایل تصویری دانلود نمی‌شود

**لوازم**
- سینک تک/دو لگن + شیرآلات، گاز رومیزی ۴ شعله (با شعله روشن و افکت bloom)،
  فر توکار، هود، یخچال، ظرفشویی — همه با رنگ دلخواه
- صفحه کابینت با `ExtrudeGeometry` و **برش واقعی** جای سینک و گاز ساخته می‌شود

**نورپردازی**
- نور مخفی LED زیر یونیت دیواری، نور داخل یونیت‌ها، نور مخفی زیر کابینت زمینی
- دمای نور (۶ preset + انتخابگر رنگ دلخواه) و شدت قابل تنظیم
- حالت شب، کنترل نور طبیعی پنجره، هالوژن‌های سقف

**فضا و کمد دیواری**
- ابعاد اتاق (عرض/عمق/ارتفاع)، کف، رنگ دیوار، پنجره، سقف
- کمد دیواری با ابعاد آزاد، ۲ تا ۵ لت، ریلی یا لولایی، آینه با بازتاب واقعی
  (`MeshReflectorMaterial`)، طبقه/ریل/کشو و نور داخلی

**رابط و خروجی**
- پلان دوبعدی زنده با درگ‌اند‌دراپ، برآورد قیمت آنی با انیمیشن اعداد،
  کپی برآورد، ذخیره طرح (JSON)، عکس PNG از صحنه
- Undo/Redo، میان‌برهای کیبورد، ذخیره خودکار طرح در حافظه مرورگر

### میان‌برها

| کلید | کار |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Shift+Z` | بازگشت / جلو |
| `←` / `→` | جابه‌جایی یونیت انتخاب‌شده |
| `O` | باز و بسته کردن درب یونیت انتخاب‌شده |
| `Delete` | حذف یونیت انتخاب‌شده |
| `Esc` | لغو انتخاب |

## ساختار

```
src/
  data/catalog.js        کاتالوگ متریال‌ها، یراق، لوازم، نماهای آماده و قیمت‌ها
  lib/layout.js          چیدمان پارامتریک، ابعاد استاندارد، برآورد قیمت
  lib/counterGeometry.js ساخت هندسه صفحه کابینت با برش‌ها (خالص و قابل تست)
  lib/textures.js        بافت‌های رویه‌ای (چوب، سنگ، سرامیک، نویز، استیل)
  store/useStudio.js     استور zustand + تاریخچه undo/redo + persist
  three/                 صحنه: اتاق، آشپزخانه، یونیت، درب، لوازم، کمد، نور و افکت
  ui/                    پنل‌ها، پلان، برآورد قیمت، ویجت‌ها و آیکون‌ها
scripts/                 تست‌ها (منطق، رندر SSR رابط، رندر هدلس صحنه)
```

## تست

| مجموعه | چه چیزی را اجرا می‌کند |
| --- | --- |
| `test:logic` | چیدمان خطی، ادغام قطعات صفحه، برش‌ها، محدودسازی ابعاد، برآورد قیمت، و هندسه واقعی صفحه با three.js |
| `test:ui` | رندر واقعی همه تب‌های پنل، پلان، برآورد و پیام‌ها روی سرور + منطق استور (افزودن/حذف/جابه‌جایی/undo/redo) |
| `test:scene` | رندر هدلس صحنه با `ReactThreeTestRenderer`: ساخت همه مش‌ها برای هر ۱۰ نوع یونیت، هر ۶ سبک درب، هر ۸ صفحه، حالت‌های کمد و نور، و بررسی نبود NaN در هندسه‌ها |

> نکته: این تست‌ها هندسه، منطق و رابط را واقعاً اجرا می‌کنند، اما WebGL و ظاهر نهایی
> نور/سایه را پوشش نمی‌دهند؛ برای آن بخش به پیش‌نمایش زنده مرورگر مراجعه کنید.
